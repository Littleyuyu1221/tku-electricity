# 校園宿舍用電分析、預測與冷氣故障風險系統

這是一套以 Streamlit 建置的互動式專題系統。它已整合淡江大學松濤一至三館近五年用電、住宿人數、開館日期、530 台現有冷氣與 2,442 筆修繕／保養紀錄，並以中央氣象署淡水站（466900）月平均溫度補足氣候特徵。

公開版本只含三館合計或類別彙整結果。原始校務檔、房號、財產編號、使用人姓名與設備級風險不放入公開儲存庫。

線上展示：https://tku-electricity-1229.streamlit.app/

## 專題研究問題

1. 宿舍用電量是否會隨住宿人日、開館天數及溫度變化？
2. 基礎設備、照明、熱水、冷氣及其他設備的估計用電占比為何？
3. 調高冷氣設定、降低照明及熱水用電可節省多少電費與碳排？
4. 月份季節基準加上住宿、溫度與開館修正後，在時間向前驗證下有多少預測能力？
5. 不同冷氣機型、時段、機齡與保養狀況如何影響耗電及故障風險？

## 系統功能

- CSV／Excel 上傳、跨年度年月排序、欄位與數值檢查
- 跨年度用電趨勢、排名、住房率、溫度及開館日分析
- 每人日與每開館日用電效率
- 基礎設備、照明、熱水、冷氣及其他用電拆解
- 冷氣、照明與熱水節能情境模擬
- 月份季節中位數＋Ridge 殘差修正的下月用電預測
- 逐月向前驗證 R²、MAE、RMSE、sMAPE 與經驗 90% 預測範圍
- 與同月份歷史中位數基準比較 MAE 改善率
- 模型影響因子及外插情境提醒
- 四個時段的冷氣耗電估算
- 冷氣機齡、運轉負載、使用時數、保養及故障紀錄風險分析
- 冷氣設備清冊批次耗電估算、故障風險排序與維護建議
- 完整 Excel 蒐集工作簿、分析結果與冷氣風險結果下載

## 資料欄位

| 欄位 | 單位 | 說明 |
|---|---:|---|
| 年份 | 西元年 | 資料年度，與月份共同識別一筆月資料 |
| 月份 | 1–12 | 資料月份；同一年度不可重複 |
| 總用電_kWh | kWh | 該月電表總用電 |
| 熱水用電_kWh | kWh | 自行上傳資料可填；校方正式資料未提供熱水獨立電表 |
| 住宿天數 | 天 | 正式資料依開館日起至學期邊界估算，並非門禁實住紀錄 |
| 住宿人數 | 人 | 當月平均住宿人數 |
| 開館天數 | 天 | 宿舍公共系統運轉天數 |
| 日平均溫度_C | °C | 當月每日平均溫度的平均值 |

## 模型方法

### 總用電預測

- 目標：松濤一至三館合計月用電
- 輸入：住宿人日、26°C 冷房度日、估算開館天數、時間趨勢與月份季節基準
- 演算法：同月份歷史中位數＋標準化 Ridge 殘差修正
- 驗證：擴張視窗逐月向前驗證，每次只使用預測月份以前的資料
- 正式結果：48 個訓練月份；24 個向前測試月份；R² 0.586、MAE 21,333 度、RMSE 27,771 度、sMAPE 16.7%
- 基準比較：同月份歷史中位數 MAE 23,040 度；混合模型改善約 7.4%
- 不確定性：以向前驗證殘差形成經驗 90% 範圍

### 冷氣耗電與故障風險

- 分時耗電：台數 × 額定功率 × 機型部分負載係數 × 機齡修正 × 溫差負載率 × 時數 × 使用率 × 天數
- 故障風險：以 3,723 筆設備－年度資料建立 L2 Logistic 迴歸，特徵含機齡、既往故障、維修／保養、館別、廠牌與型號族群
- 驗證：依年份向前預測 2022–2025，ROC-AUC 0.661、average precision 0.316、Brier score 0.163
- 批次分析：上傳完整蒐集工作簿或冷氣清冊，依設備群組輸出耗電、風險排名及維護建議
- 重要限制：現有清冊缺少已汰換設備，存在存活者偏差；因此網站將結果稱為「相對風險排序」，不宣稱為精準故障率

## 執行方式

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## 專題交付物

- `app.py`：互動式分析網站
- `宿舍用電資料範本.csv`：資料填寫範本
- `宿舍用電與冷氣資料蒐集範本.xlsx`：含月用電、冷氣清冊、保養故障紀錄、資料字典與品質檢核的完整工作簿
- `大四專題報告.docx`：正式候選版書面報告，含敏感度分析、實際系統畫面、模型卡與擴充口試問答
- `預覽-首頁.png`、`預覽-用電預測.png`、`預覽-冷氣風險.png`：線上部署版本的實際畫面，可用於報告、海報與口試備援
- `大四專題口試簡報.pptx`：12 頁口試簡報，含三張實際部署畫面、離線展示備援、逐頁講者備註與資料來源
- `口試講稿與答辯手冊.md`：8 分鐘逐頁講稿、3 分鐘網站展示流程與 15 題常見問答
- `資料蒐集與驗收清單.md`：取得校方資料後的執行清單
- `校方資料申請與研究使用說明.docx`：可交給宿舍、總務或營繕單位的正式資料申請與授權文件
- `校方資料申請信範本.md`：可直接修改姓名、系所與指導教授後寄出的申請信
- `專題送審完成度報告.md`：逐項列出已驗證交付物、仍待校方資料與正式送件條件

## 送審前自動驗證

解壓完整專題包後執行 `python final_readiness.py`，可重新檢查程式語法、模型回歸測試、報告與簡報結構、Excel 蒐集工具及完整壓縮包；在開發工作區則執行 `python work/final_readiness.py`。驗證器會把姓名、校方正式資料、系所格式與人工逐頁版面檢查列為待完成，不會誤報為技術測試已涵蓋。

## 研究誠信與限制

目前內建的 12 個月數值是示範資料，不是校方正式量測結果。報告或口試不得把示範模型數值宣稱為實際節電成效或真實故障率。正式成果應換成經授權的電表、住宿與設備維修資料，保留資料來源、量測期間、缺值處理及模型版本紀錄。碳排換算預設採 2025 年產業用電係數 0.466 kg CO₂e／kWh，正式盤查仍須依資料年度及學校電價類別更新。
