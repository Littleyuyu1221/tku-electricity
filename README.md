# 校園宿舍用電分析與節能決策系統

## 專題目標

使用月用電、熱水用電、住宿人數、住宿天數與平均溫度，建立可互動的用電分析儀表板，找出高耗能月份、拆解能源用途，並量化冷氣、照明及熱水的節能效益。

## 主要功能

- CSV／Excel 真實資料上傳與格式檢查
- 月用電趨勢、溫度關聯與能源結構圖
- 總電費、單位用電與碳排指標
- 冷氣溫度、照明及熱水節能情境模擬
- 以溫度與住宿人日建立線性迴歸示範模型
- 分析結果下載

## 執行方式

在本資料夾安裝套件後執行：

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## 上傳資料欄位

`月份`、`總用電_kWh`、`熱水用電_kWh`、`住宿天數`、`住宿人數`、`平均溫度_C`

## 報告可用研究問題

1. 宿舍用電是否隨平均溫度與住宿人日變化？
2. 哪一類設備是主要耗能來源？
3. 調高冷氣設定、改善照明與熱水管理可節省多少電費及碳排？
4. 現有資料能否建立可解釋的月用電預測模型？

> 目前內建數值是示範資料。正式成果應換成校方或電表的真實資料，並在報告中註明來源及量測期間。
